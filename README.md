# Product CRUD API – Express.js

A secure Product CRUD API built with **Express.js**, featuring **JWT authentication**, **refresh tokens**, and **role-based authorization**.  
This project uses **MongoDb**, fetch and map on external api save same to user-todo model, it is intended for scaling, prototyping, and API architecture practice.

---

## Features

- Create, Read, Update, and Delete (CRUD) products
- JWT-based authentication (Access & Refresh tokens)
- Role-based authorization (Admin / User)
- Protected routes using middleware
- image url saved to cloudinary using multer
- MongoDB
- Environment variable support with dotenv
- Centralized error handling

---

## Tech Stack

- Node.js
- Express.js
- JSON Web Tokens (JWT)
- dotenv
